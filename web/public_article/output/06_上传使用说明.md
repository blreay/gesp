## 二、如何将 HTML 导出为图片

HTML 设计稿需要导出为 PNG/JPG 图片后才能上传微信。

### 方法一：浏览器截图（推荐）

1. 用 **Chrome 浏览器** 打开 HTML 文件（双击文件或拖入浏览器窗口）
2. 确保浏览器缩放比例为 **100%**（快捷键 `Ctrl+0` / `Cmd+0`）
3. 按 `F12` 打开开发者工具
4. 按 `Ctrl+Shift+P`（Mac: `Cmd+Shift+P`），输入 `screenshot`
5. 选择 **「Capture full size screenshot」**
6. 自动下载一张精确尺寸的 PNG 图片

> 注意：截图前确保 HTML 文件和图片文件（logo.jpg, rmd01-04.jpg）在正确的相对路径位置。HTML 文件在 `output/` 文件夹中，图片在上一级目录。

### 方法二：在线工具

如果不方便使用开发者工具，可以用在线 HTML 转图片工具：
- 将 HTML 内容粘贴到在线渲染器
- 设置宽度 900px
- 导出为 PNG

### 方法三：命令行截图

如果本机安装了 Node.js，可使用 puppeteer 截图：

```bash
# 安装
npm install puppeteer

# 截图脚本示例
node -e "
const puppeteer = require('puppeteer');
(async () => {
  const browser = await puppeteer.launch();
  const page = await browser.newPage();
  await page.setViewport({width: 900, height: 383});
  await page.goto('file://$(pwd)/output/01_头图_header_banner.html');
  await page.screenshot({path: 'output/01_头图.png', fullPage: true});
  await browser.close();
})();
"
```

## 三、微信公众号上传指引

### 3.1 设置公众号头图

1. 登录 [微信公众平台](https://mp.weixin.qq.com)
2. 左侧菜单 →「设置与开发」→「公众号设置」
3. 点击头像区域右侧的「头图」编辑
4. 上传 `01_头图` 导出的 PNG 图片
5. 调整裁剪区域，确保核心信息在安全区内

> 💡 头图推荐尺寸 900×383，但微信会根据不同入口做适配裁剪。文字信息尽量集中在画面中央 60% 区域。

### 3.2 推文封面图上传

**发布文章时：**

1. 在文章编辑页面，点击顶部「封面」区域
2. 上传 `02_封面A` 或 `03_封面B` 导出的图片
3. 微信会提示裁剪 —— 拖动调整确保标题文字完整可见

**封面图尺寸要求：**

| 位置 | 比例 | 建议尺寸 | 说明 |
|------|------|---------|------|
| 头条封面（大图） | 2.35:1 | 900 × 383 px | 本模板已适配 |
| 次条封面（小图） | 1:1 | 200 × 200 px | 需另行裁剪 |

**安全区提醒：**
- 大图在订阅号列表中会被裁剪为 **2.35:1**（已适配）
- 在朋友圈分享时会被裁剪为约 **1.55:1**（画面上下各约15%会被裁切）
- 重要信息（标题、数据、品牌标识）请保持在 **画面中央 70% 区域**

### 3.3 封面模板使用方法

两套模板的使用场景：

| 模板 | 适用场景 | 设计风格 |
|------|---------|---------|
| 模板A（技术产品类） | 技术解读、产品发布、核心工艺介绍 | 白底 + 设备实拍，数据突出 |
| 模板B（案例行业类） | 项目案例、行业观点、应用场景 | 左紫右图分屏，正式商务 |

**替换标题文字：**
1. 用代码编辑器（VS Code、记事本等）打开 HTML 文件
2. 搜索需要修改的文字内容
3. 替换为新的文章标题
4. 保存 → 浏览器刷新 → 重新截图导出

**常见替换位置：**
- 模板A：修改 `class="title-main"` 内的标题文字、`class="title-sub"` 内的副标题
- 模板A：修改 `class="category"` 内的分类标签（核心技术 → 行业洞察 等）
- 模板B：修改 `class="title-main"` 内的标题、`class="tag"` 内的标签文字
- 模板B：修改 `class="title-desc"` 内的描述文字、`class="pill"` 内的标签

### 3.4 菜单栏配置

1. 微信公众平台 →「内容与互动」→「自定义菜单」
2. 按照 `04_菜单栏视觉概念.html` 中的结构配置：

```
技术方案（一级）
  ├── 核心技术   → 链接至技术介绍文章
  ├── 产品中心   → 链接至产品详情文章
  └── 工程案例   → 链接至案例合集文章

走进睿美达（一级）
  ├── 公司介绍   → 链接至企业简介文章
  ├── 生产基地   → 链接至工厂图文文章
  ├── 资质荣誉   → 链接至荣誉展示文章
  └── 新闻动态   → 链接至历史文章列表

联系我们（一级）
  ├── 技术咨询   → 跳转客服会话
  └── 商务合作   → 链接至联系方式页面
```

3. 点击「保存并发布」

### 3.5 自动回复配置

1. 微信公众平台 →「内容与互动」→「自动回复」
2. **关注后自动回复**：开启 → 粘贴 `05_全套文案.md` 中的「关注后自动回复」内容
3. **关键词自动回复**：
   - 添加规则「技术」→ 粘贴对应文案
   - 添加规则「产品」→ 粘贴对应文案
   - 添加规则「案例」→ 粘贴对应文案
   - 添加规则「合作」→ 粘贴对应文案
4. 每条自动回复文字限制 600 字，超出需精简

## 四、视觉规范速查

### 品牌色值

| 颜色 | HEX | 用途 |
|------|-----|------|
| 达标金 | `#E8880C` | 重点数据、CTA按钮、分隔线 |
| 皇家紫 | `#312D72` | 标题、品牌标识、深色背景 |
| 浅青蓝 | `#E0F7FA` | 信息卡片背景、辅助色块 |
| 浅环保绿 | `#E8F5E9` | 环保相关标签、成功状态 |
| 银灰 | `#ECEFF1` | 次要背景、分隔线、边框 |
| 白色 | `#FFFFFF` | 主背景 |
| 正文黑 | `#1A1A2E` | 标题、正文 |
| 辅助灰 | `#6B6B8A` | 副标题、说明文字 |

### 字体规范

- **中文主字体**：PingFang SC / Microsoft YaHei / Noto Sans SC
- **英文/数字**：Helvetica Neue / Arial
- **标题**：Bold 或 Black（700-900）
- **正文**：Regular（400）
- **行高**：标题 1.3 - 1.4，正文 1.6 - 1.8

### 设计要素

- 以白色为主基调，搭配浅色背景色块
- 使用设备实拍照片作为主要装饰元素
- 可用工艺管线、流程箭头、几何点阵作为辅助图形
- 禁止大面积使用河道/河流/湖泊图片
- 数据突出展示（30%-50%、100%）
- 品牌标识始终出现在画面中

## 五、后续维护建议

1. **文章封面**：每篇推文根据内容选择模板A或模板B，修改标题文字后导出
2. **头图**：每季度可更换一次，保持新鲜感，但配色体系不变
3. **菜单栏**：重要文章发布后及时更新对应子菜单的链接
4. **自动回复**：每季度检查更新案例数据和联系方式
5. **风格一致性**：所有图文内容保持达标金+皇家紫的品牌配色体系
