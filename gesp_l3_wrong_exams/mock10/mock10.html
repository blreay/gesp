一、单选题（每题 2 分，共 30 分）
1. 老板让你存"学生成绩"，用学号（string 类型，如 "S001"）查分数（int），下面哪个是绝对正确且安全的写法（ ）。
A. map<int, int> 成绩; 成绩["S001"] = 100;
B. unordered_map<string, int> 成绩; 成绩["S001"] = 100;
C. map<string, string> 成绩; 成绩["S001"] = 100;
D. vector<int> 成绩; 成绩["S001"] = 100;
2. `map<int, string> 电话簿; 电话簿[1001] = "王大胆";` 之后执行 `if (电话簿[9999] == "") {...}` 想"看一下 9999 是否存在"，这样写会导致什么后果（ ）。
A. 完全没有副作用，只是单纯的一次查询
B. 编译错误
C. 会"偷偷"在 map 里插入一个 key 为 9999、value 为空字符串的新记录（`[]` 运算符查不到会自动创建）
D. 程序崩溃
3. 想"安全地"检查 map 中是否存在某个 key，而不会意外插入新记录，应该使用（ ）。
A. m.find(key) == m.end() 或 m.count(key)
B. m[key] == 0
C. m.size() > 0
D. m.begin() == m.end()
4. 关于 `map` 和 `unordered_map` 的区别，说法正确的是（ ）。
A. map 是无序的，unordered_map 是有序的
B. 两者查找的时间复杂度完全一样
C. unordered_map 不能用 [] 运算符
D. map 内部按 key 自动排序（查找 O(log n)），unordered_map 内部是哈希表（平均查找 O(1)，但不保证顺序）
5. `map<int, string> m; m[5]="e"; m[1]="a"; m[3]="c";` 之后用 `for (auto& p : m) cout << p.first << " ";` 遍历，输出顺序是（ ）。
A. 5 1 3（插入顺序）
B. 1 3 5（按 key 从小到大自动排序）
C. 顺序不确定，每次运行都可能不同
D. 5 3 1（按 key 从大到小）
6. 已知 `map<int,int> m; m[1001]="王大胆";` 会不会有问题（ ）。（提示：注意 map 的模板参数）
A. 完全没问题，正常运行
B. 运行时崩溃
C. 编译错误，因为 value 类型声明为 int，不能直接赋值字符串字面量
D. 会自动把 map 的 value 类型改成 string
7. 关于 `m.count(key)` 的返回值，说法正确的是（ ）。
A. 返回该 key 对应 value 的具体数值
B. 对于 map/unordered_map，返回 0（不存在）或 1（存在），因为 key 唯一
C. 永远返回 0
D. 返回 map 的大小
8. 标准 C 语言里没有内置的 map 容器，如果要实现"工号查姓名"的功能，最接近的手工做法是（ ）。
A. 自己维护一个按工号排序的结构体数组，用 bsearch 二分查找
B. C 语言其实也内置了 map，用法和 C++ 完全一样
C. 不可能实现，C 语言无法做查找功能
D. 只能用 for 循环从文件里重新读一遍
9. 一段代码把课本上带行号的代码（如 "1 #include <iostream>"）连同行号一起敲进了编辑器，这样做的后果是（ ）。
A. 编译器会自动识别并忽略行号，正常编译
B. 行号本身会被当成代码的一部分，通常会导致编译错误
C. 程序能正常运行，只是多输出几个数字
D. 只有 GCC 编译器会报错，其他编译器不会
10. 表达式 `[(1,2)*2]*3`，如果去掉方括号写成 `(1,2)*2*3`，则该表达式在 C++ 中（ ）。
A. 不合法，编译错误
B. 合法，`(1,2)` 是逗号表达式，值为 2，整个表达式的值是 2*2*3=12
C. 合法，但值是 1*2*3=6
D. 合法，但值是未定义行为
11. 关于 bit、Byte、KB 的说法，正确的是（ ）。
A. bit 可以直接换算成 KB
B. 1 Byte = 1024 bit
C. 1 KB = 1000 bit
D. 正确的递进关系是 bit → Byte → KB → MB，其中 1 Byte=8 bit，1 KB=1024 Byte
12. `unordered_map<string, int> freq; string s; while (cin >> s) freq[s]++;` 这段代码的功能是（ ）。
A. 统计输入的单词个数（去重后剩几个）
B. 按字典序打印所有单词
C. 统计每个单词在输入中出现的次数（词频统计）
D. 删除重复的单词
13. 关于 `map<K,V>` 的迭代器 `it`，`it->first` 和 `it->second` 分别表示（ ）。
A. 第一个元素和最后一个元素
B. 当前指向的键值对的 key 和 value
C. map 的大小和容量
D. 前一个迭代器和后一个迭代器
14. 已知 1 个中文汉字在 GBK 编码下占用 2 个 Byte，一篇纯中文文档有 500 个汉字，大约占用（ ）。
A. 1000 Byte（约 1 KB）
B. 500 Byte
C. 2000 KB
D. 500 bit
15. 关于下面这行 C++ 代码，说法正确的是（ ）：`printf("Hello,GESP!");`
A. 配对的双引号内，不可以出现汉字
B. 配对的双引号可以直接改成配对的单引号，效果不变
C. 配对的双引号可以改成三个连续的英文单引号，效果不变
D. 配对的双引号可以改成三个连续的英文双引号（即 """Hello,GESP!"""），输出效果不变
二、判断题（每题 2 分，共 20 分）
1. `map` 和 `unordered_map` 都要求 key 必须是 int 类型，不能用 string 做 key。（ ）
✔ 正确
✘ 错误
2. 用 `[]` 运算符查询一个不存在的 key 时，会自动在容器里插入一条以该 key、默认构造的 value 组成的新记录。（ ）
✔ 正确
✘ 错误
3. 只需要查找，不关心遍历顺序时，通常优先选用 `unordered_map`，因为它平均查找效率更高。（ ）
✔ 正确
✘ 错误
4. map 中的 key 可以重复出现多次，每次赋值都会新增一条记录。（ ）
✔ 正确
✘ 错误
5. 表达式 `[(1,2)*2]*3` 中的方括号 `[` `]` 在 C++ 里是数组下标运算符的专用符号，不能像数学里那样当作括号使用，所以整体不是合法的表达式。（ ）
✔ 正确
✘ 错误
6. 1 KB 在计算机存储领域任何时候都严格等于 1000 Byte，绝无例外（磁盘厂商和操作系统的算法完全一致）。（ ）
✔ 正确
✘ 错误
7. 1 TB 硬盘在电脑属性里显示的容量往往比标称的略小（例如显示约 931 GB），这是因为厂商按 1000 进制计算容量，而操作系统按 1024 进制显示。（ ）
✔ 正确
✘ 错误
8. `map` 底层通常基于平衡二叉搜索树（如红黑树）实现，这也是它能自动按 key 排序、查找复杂度为 O(log n) 的原因。（ ）
✔ 正确
✘ 错误
9. `unordered_map` 的"unordered"意味着它内部完全不做任何组织，每次查找都要遍历所有元素（时间复杂度 O(n)）。（ ）
✔ 正确
✘ 错误
10. 在实际比赛/考试中，如果需要按 key 从小到大顺序输出结果，应该选择 `map` 而不是 `unordered_map`。（ ）
✔ 正确
✘ 错误
三、编程题（每题 25 分，共 50 分）

编程题 1：单词词频统计

时间限制：1.0 s   内存限制：128.0 MB

【问题描述】

输入若干个用空格/换行分隔的单词（全部为小写英文字母，直到输入结束 EOF），请统计每个不同单词出现的次数，按单词的字典序从小到大输出"单词 次数"。

【输入描述】

若干行单词，以文件结束（EOF）为输入终止标志。

【输出描述】

按字典序输出每个不同单词及其出现次数，每行一个，用空格分隔。

样例输入

the quick fox jumps
the lazy fox
the fox runs

样例输出

fox 3
jumps 1
lazy 1
quick 1
runs 1
the 3

配套测试程序：mock10_prob1_word_frequency.cpp

编程题 2：查找重复的学号

时间限制：1.0 s   内存限制：128.0 MB

【问题描述】

输入 n 个学号（字符串，如 "S001"），请找出其中第一个出现"重复"的学号（即从左到右扫描，第一个此前已经出现过的学号），并输出它；如果没有重复的学号，输出 "NONE"。请使用 map 或 unordered_map 实现高效查找（不要用双重循环暴力比较）。

【输入描述】

第一行一个整数 n（1 ≤ n ≤ 100000）；第二行 n 个学号，用空格分隔。

【输出描述】

输出第一个重复出现的学号，或 "NONE"。

样例输入 1

5
S001 S002 S003 S002 S004

样例输出 1

S002

样例输入 2

3
S001 S002 S003

样例输出 2

NONE
