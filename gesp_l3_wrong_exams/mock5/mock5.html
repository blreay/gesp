for (int i = 1; i < n; i++) {
    int key = a[i];
    int j = i - 1;
    while (j >= 0 && __________) {
        a[j + 1] = a[j];
        j--;
    }
    a[j + 1] = key;
}
A. a[j] < key
B. a[j] > key
C. a[j+1] > key
D. a[j] == key
4. 下面代码通过找最小值下标并交换实现排序，这段代码使用的排序算法是（ ）。
for (int i = 0; i < n - 1; i++) {
    int minIdx = i;
    for (int j = i + 1; j < n; j++)
        if (a[j] < a[minIdx]) minIdx = j;
    swap(a[i], a[minIdx]);
}
A. 冒泡排序
B. 插入排序
C. 选择排序
D. 快速排序

时间限制：1.0 s   内存限制：128.0 MB

给定 n 名学生的姓名和成绩，请按成绩从高到低排序输出姓名；若成绩相同，按输入顺序在前的姓名排在前面（即要求排序稳定）。

第一行一个整数 n（1 ≤ n ≤ 100）；接下来 n 行，每行一个不含空格的姓名字符串和一个整数成绩，用空格分隔。

【输出描述】

4

Bob 95
Cathy 88
David 72

Alice
Cathy
David
