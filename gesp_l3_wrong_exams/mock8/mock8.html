一、单选题（每题 2 分，共 30 分）
1. 下面递归函数用于求斐波那契数列第 n 项，它的时间复杂度是（ ）。
int fib(int n) {
    if (n <= 1) return n;
    return fib(n - 1) + fib(n - 2);
}
A. O(n)
B. O(n²)
C. O(n³)
D. O(2ⁿ)
2. 下面用递推（循环）方式求斐波那契数列第 n 项，它的时间复杂度是（ ）。
int fib(int n) {
    if (n <= 1) return n;
    int a = 0, b = 1;
    for (int i = 2; i <= n; i++) {
        int c = a + b;
        a = b; b = c;
    }
    return b;
}
A. O(n)
B. O(n²)
C. O(2ⁿ)
D. O(log n)
3. 用递归法求 n 的阶乘（`f(n) = n * f(n-1)`，f(0)=1），它的时间复杂度是（ ）。
A. O(n)
B. O(n²)
C. O(2ⁿ)
D. O(n!)
4. 下面递归函数 cellRecur(n) 的时间复杂度是（ ）。
int cellRecur(int n) {
    if (n == 1) return 1;
    return cellRecur(n - 1) + cellRecur(n - 1) + 1;
}
A. O(n²)
B. O(2ⁿ)
C. O(1)
D. O(n)
5. 用位运算枚举一个长度为 n 的数组的所有子集（`1<<n` 种子集，每种子集内层再遍历 n 个元素检查是否属于该子集），整个算法的时间复杂度是（ ）。
A. O(n²)
B. O(n × 2ⁿ)
C. O(1)
D. O(n³)
6. 下面 climb(n) 函数用迭代方式计算类似斐波那契数列的值（爬楼梯问题），climb(6) 的返回值是（ ）。
int climb(int n) {
    if (n <= 2) return n;
    int a = 1, b = 2;
    for (int i = 3; i <= n; i++) {
        int c = a + b;
        a = b; b = c;
    }
    return b;
}
A. 13
B. 8
C. 5
D. 10
7. "递推算法"和"递归算法"最主要的区别是（ ）。
A. 递推算法一定比递归算法快，没有例外
B. 递归算法不会用到函数调用栈
C. 递推是从已知的初始状态逐步推出后续状态（自底向上，通常用循环）；递归是函数调用自身，从大问题分解出小问题（自顶向下）
D. 两者没有任何区别，只是叫法不同
8. 使用 `` 中的 `steady_clock` 测量一段代码运行耗时，其相对于 `system_clock` 最大的优势是（ ）。
A. steady_clock 的精度总是更高
B. steady_clock 不受用户或系统手动调整墙上时钟（系统时间）的影响，只会单调递增，更适合测量耗时
C. steady_clock 可以直接转换成日历时间字符串，system_clock 不能
D. steady_clock 只能在 C 语言中使用
9. 关于 C 语言 `time.h` 中的 `time(NULL)` 和 C++11 `` 中的 `system_clock::now()`，说法正确的是（ ）。
A. time(NULL) 精度能到纳秒
B. system_clock::now() 只能精确到秒，和 time(NULL) 完全一样
C. 两者都无法获得当前时间
D. time(NULL) 精度只到秒，而 system_clock 通常能获得更高精度（如毫秒、微秒）
10. 用 `high_resolution_clock` 测量 `sort` 排序 100 万个数所花费的时间，正确的写法思路是（ ）。
A. 只需要调用一次 now()，无需在排序前后各调用一次
B. time(NULL) 精度更适合此场景
C. 排序前调用 now() 记录起点，排序后再调用 now() 记录终点，用 duration_cast 求两者之差
D. 直接用 sort 函数的返回值即为耗时
11. 关于时间复杂度的说法，正确的是（ ）。
A. 时间复杂度就是程序实际运行的秒数
B. 时间复杂度描述的是算法基本操作次数随输入规模 n 增长的渐进趋势，与具体机器速度无关
C. O(n) 的算法一定比 O(n²) 的算法运行得更快（对任意输入规模都是）
D. 递归算法的时间复杂度不可能是指数级的
12. 用记忆化（缓存已经算过的结果）优化递归求斐波那契数列，可以把时间复杂度从 O(2ⁿ) 降低到（ ）。
A. O(n)
B. O(2ⁿ)（不变）
C. O(1)
D. O(n³)
13. 下面代码用递归实现二分查找，在长度为 n 的有序数组中查找目标值，时间复杂度是（ ）。
int bsearch(int a[], int lo, int hi, int target) {
    if (lo > hi) return -1;
    int mid = (lo + hi) / 2;
    if (a[mid] == target) return mid;
    if (a[mid] < target) return bsearch(a, mid+1, hi, target);
    return bsearch(a, lo, mid-1, target);
}
A. O(n)
B. O(n²)
C. O(log n)
D. O(2ⁿ)

D. 2ⁿ - 1

A. 递归函数不需要终止条件（base case），程序会自动停止
B. 递归函数如果没有正确的终止条件，可能导致栈溢出（stack overflow）
C. 递归函数的效率永远高于等价的循环实现
