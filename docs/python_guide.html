0.2 一题两写：直观感受区别

题目：读入 n，输出 1～n 中所有偶数的和。

C++ 写法
int n, s = 0;
cin >> n;
for (int i = 1; i <= n; i++) {
    if (i % 2 == 0) s += i;
}
cout << s << endl;
Python 写法（示例输入：10）
n = int(input())
s = 0
for i in range(1, n + 1):
    if i % 2 == 0:
        s += i
print(s)
30
⚠ 缩进错误是头号杀手 同一个代码块内缩进必须一致。建议统一用 4 个空格，不要 Tab 和空格混用，否则会报 IndentationError。

1. 输入输出与类型转换⏱ 15 分钟

1.1 input()：读进来的永远是字符串

input() 读取一整行，返回字符串（不含末尾换行）。要做数学计算，必须先转换类型。

例 1　示例输入：第一行 3，第二行 4
a = input()
b = input()
print(a + b)            # 字符串拼接！
print(int(a) + int(b))  # 转成整数再相加
34
7
例 2　读一个整数、一个小数（示例输入：第一行 5，第二行 2.5）
n = int(input())
x = float(input())
print(n * x)
12.5
⚠ 常见错误
  • 忘记 int()：input() + 1 会报 TypeError（字符串不能加整数）。
  • int("3.5") 会报 ValueError，要写 int(float("3.5"))，结果是 3。
  • 如果是自动判题，一般不要写 input("请输入：") 这种提示文字——提示也会被当成输出，可能导致判错。具体以题目要求为准。

1.2 一行读入多个数：split() + map()

input().split() 按空白把一行切成若干字符串；map(int, ...) 把每一个都转成整数。

例 1　示例输入：3 5
a, b = map(int, input().split())
print(a + b, a * b)
8 15
例 2　个数不定，存进列表（示例输入：1 2 3 4）
nums = list(map(int, input().split()))
print(nums)
print(sum(nums))
[1, 2, 3, 4]
10
例 3　第一行是 n，第二行是 n 个数（示例输入：第一行 3，第二行 10 20 30）
n = int(input())
a = list(map(int, input().split()))
print(max(a) - min(a))
20
例 4　n 个数分在 n 行（示例输入：3 / 7 / 8 / 9，各占一行）
n = int(input())
total = 0
for i in range(n):
    total += int(input())   # 每行读一次
print(total)
24
⚠ 看清输入格式！ a, b = map(int, input().split()) 要求同一行恰好两个数。如果两个数分在两行，就要调用两次 input()，否则会报 ValueError。

🔁 C++ 习惯提醒
  • 6 / 2 得到 3.0 而不是 3。题目要输出整数时，用 // 或 int()。

    return x ** n

⚠ 常见错误
  • 函数中没写 return，返回的就是 None：print(f()) 会打印出 None。
  • 函数必须先定义（def）再调用，在 def 之前调用会报 NameError。
  • 不需要写返回值类型和参数类型，def int f(int x) 是 C++ 写法。

6.3 局部变量与全局变量

函数里赋值的变量默认是局部变量。如果要在函数里修改外面的全局变量，需要先声明 global。

count = 0
def add():
    global count      # 没有这一行会报 UnboundLocalError
    count += 1

add()
add()
print(count)
2
💡 小贴士 只是读取全局变量，或者调用 a.append(x) 这类方法修改全局列表，不需要写 global；只有对变量重新赋值（包括 +=）时才需要。

def is_prime(n):
    if n < 2:
        return False
    for i in range(2, int(n ** 0.5) + 1):

            return False
    return True

7.6 简单递归（了解即可）

递归 = 函数自己调用自己，必须有结束条件。

def fact(n):
    if n <= 1:
        return 1
    return n * fact(n - 1)

def fib(n):          # 1 1 2 3 5 8 ...
    if n <= 2:
        return 1
    return fib(n - 1) + fib(n - 2)

print(fact(5), fib(10))
120 55
⚠ 注意 Python 默认递归深度上限约为 1000 层，太深会报 RecursionError。fib 递归在 n 较大（比如 40）时非常慢，这时改用循环： 
a, b = 1, 1
for i in range(8):     # 求第 10 项
    a, b = b, a + b
print(b)
55

9.3 易错点清单（逐条过一遍）

  • input() 读进来的是字符串，算数前先 int()
  • range(a, b) 不包含 b；1～n 要写 range(1, n + 1)
  • / 结果是小数，整除用 //；拆数位用 n //= 10
  • 负数：-7 // 2 == -4，-7 % 2 == 1
  • and / or / not，不是 && / || / !
  • i += 1，没有 i++（++i 不报错，但什么也不做）
  • if / elif / else / for / while / def 末尾都要加冒号，下一行要缩进
  • True / False / None 首字母大写
  • a.sort() 返回 None，不要写 a = a.sort()
  • 字符串方法返回新字符串，记得重新赋值：s = s.upper()
  • random.randint(a, b) 两端都包含
  • 二维列表用 [[0] * m for _ in range(n)]
  • 不要用 max / sum / list / str 当变量名
  • 函数里修改全局变量要写 global
  • 输出格式严格照题目来：空格、换行、小数位数、不要多余的提示文字
