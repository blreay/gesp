第1题 答案：A

156转二进制：156÷2=78...0, 78÷2=39...0, 39÷2=19...1, 19÷2=9...1, 9÷2=4...1, 4÷2=2...0, 2÷2=1...0, 1÷2=0...1。从下往上读：10011100。验证：128+16+8+4=156。

第2题 答案：B

二进制小数 0.1101 转十进制：1×2^(-1) + 1×2^(-2) + 0×2^(-3) + 1×2^(-4) = 0.5 + 0.25 + 0 + 0.0625 = 0.8125。

第3题 答案：D

12的二进制：1100，10的二进制：1010。按位与：1100 & 1010 = 1000 = 8。

第4题 答案：A

异或交换是经典算法：a^=b使a=a^b；b^=a使b=b^(a^b)=a；a^=b使a=(a^b)^a=b。三步完成交换。

第5题 答案：C

左移n位相当于乘以2^n。5 << 3 = 5 × 2^3 = 5 × 8 = 40。

第6题 答案：B

8位补码范围是-128~127。-128的补码是10000000。这是一个特殊值，它没有对应的原码（因为+128超出了8位有符号数范围）。

第16题 答案：对

255 = 15×16+15 = F×16+F = FF(十六进制)。

第17题 答案：错

八进制只能使用0-7这8个数字，数字9不是合法的八进制数字，所以"19"不是合法的八进制数。

第18题 答案：对

n&1取n的最低位，对于非负整数等价于n%2。当n为奇数时结果为1，偶数时为0。

第19题 答案：对

异或运算的性质：任何数与自身异或结果为0。因为相同位异或得0。

第20题 答案：错

C++标准不支持变长数组(VLA)。虽然某些编译器（如GCC）作为扩展支持，但这不是标准C++语法。应使用常量或动态分配。

第21题 答案：错

数组越界访问不会导致编译错误，而是运行时的未定义行为。编译器不会检查数组下标是否越界。

第22题 答案：对

局部变量存储在栈上，函数调用结束时栈帧被释放，局部变量随之销毁。

第23题 答案：错

引用传递传递的是变量的别名，函数内对形参的修改会直接影响实参。值传递则是副本，不影响实参。两者效果不同。

第24题 答案：对

标准ASCII码表中，'0'=48, 'A'=65, 'a'=97。这是需要记住的基础知识。

编程题参考代码

编程题1：数位之和

#include <iostream>
using namespace std;

int main() {
    long long n;
    cin >> n;
    int steps = 0;
    while (n >= 10) {
        long long sum = 0;
        while (n > 0) {
            sum += n % 10;
            n /= 10;
        }
        n = sum;
        steps++;
    }
    cout << n << " " << steps << endl;
    return 0;
}

思路：反复对数字求各位数字之和，直到结果小于10为止。注意使用long long处理大数。

编程题2：矩阵对角线

#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    int a[100][100];
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++)
            cin >> a[i][j];

    long long sum = 0;
    for (int i = 0; i < n; i++) {
        sum += a[i][i];           // 主对角线
        if (i != n - 1 - i)
            sum += a[i][n-1-i];   // 副对角线（避免重复）
    }
    cout << sum << endl;
    return 0;
}

思路：遍历行号i，a[i][i]是主对角线元素，a[i][n-1-i]是副对角线元素。当i==n-1-i时（N为奇数的中心位置），只加一次。
