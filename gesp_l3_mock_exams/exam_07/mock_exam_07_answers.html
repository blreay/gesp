单选题详细解析

第1题 答案：C

45的二进制为00101101。取反得11010010，加1得11010011。所以-45的8位补码为11010011。验证：-128+64+16+2+1=-128+83=-45。

第2题 答案：B

0x3F = 3×16 + 15 = 48 + 15 = 63。

第3题 答案：A

0xAB = 10×16+11 = 171，二进制为10101011。右移4位：00001010=10（即高4位A=10）。与0x0F：取低4位00001011=11（即B=11）。输出"10 11"。

第4题 答案：D

100的二进制为1100100。n | (1<<3)：将第3位置1，得1101100=108。n & ~(1<<2)：将第2位清0，1101100 & 1111011 = 1101000 = 104。

第5题 答案：B

2的幂的二进制只有一个1（如8=1000）。n-1会把该位变0，低位全变1（如7=0111）。n&(n-1)=0。这是经典的判断2的幂的方法。注意n必须为正数。

第6题 答案：C

最高位为1表示负数。补码10000001，取反得01111110=126，加1得127。所以表示-127。

第7题 答案：A

p = a+2，指向a[2]=30。p-1指向a[1]=20，p+1指向a[3]=40。输出"20 40"。

第8题 答案：D

p指向a[0]。*(p+3)即a[3]，*p即a[0]=5，*(p+4)即a[4]=9。a[3] = 5 + 9 = 14。数组变为{5,3,8,14,9}。

第9题 答案：C

这是斐波那契数列：f(1)=1, f(2)=1, f(3)=2, f(4)=3, f(5)=f(4)+f(3)=3+2=5。等等，让我重新计算：f(0)=1, f(1)=1, f(2)=f(1)+f(0)=2, f(3)=f(2)+f(1)=3, f(4)=f(3)+f(2)=5, f(5)=f(4)+f(3)=8。答案为8。

第10题 答案：B

递归先处理g(n/10)再输出n%10。g(1234)→g(123)→g(12)→g(1)→g(0)(返回)。回溯时依次输出：1%10=1，12%10=2，123%10=3，1234%10=4。最终输出"1234"。

第11题 答案：A

冒泡排序第一趟从左到右比较相邻元素：(5,2)交换→{2,5,8,3,1}；(5,8)不换；(8,3)交换→{2,5,3,8,1}；(8,1)交换→{2,5,3,1,8}。最大值8到末尾。

第12题 答案：C

选择排序每轮从剩余元素中选最小值，需要比较(n-1)+(n-2)+...+1 = n*(n-1)/2次，与数据初始顺序无关。

第13题 答案：B

a++是后置递增，先取a=3参与运算，运算后a变4。++b是前置递增，b先变6再参与运算。c = 3 + 6 = 9。最终a=4, b=6, c=9。

第14题 答案：A

条件i%3==0 && i%5==0等价于i%15==0。1到100中15的倍数：15+30+45+60+75+90=315。

第15题 答案：D

逐步计算XOR：0^2=2, 2^4=6, 6^6=0, 0^8=8, 8^10=2。二进制：1000^1010=0010=2。答案为2。

判断题详细解析

第16题 答案：对

优化版冒泡排序加入标志位，若一趟没有交换则提前结束。数据已有序时只需一趟扫描O(n)即可确认。

第17题 答案：错

选择排序不稳定。例如{5a, 5b, 2}，第一趟选最小值2与5a交换，得{2, 5b, 5a}，两个5的相对顺序改变。

第18题 答案：对

1<<31将1移到32位int的最高位（符号位），得到0x80000000，在有符号int中表示INT_MIN=-2147483648，是负数。

第19题 答案：错

~0将所有位取反，0的所有位为0，取反后全为1，即0xFFFFFFFF，在有符号int中等于-1，不是1。

第20题 答案：对

指针变量的值是内存地址。通过解引用操作符*才能访问该地址存储的值。

第21题 答案：错

p+5指向a[5]，已经越过数组最后一个元素a[4]。p+4才指向最后一个元素a[4]。p+5指向的是数组尾后位置。

第22题 答案：对

插入排序对于近乎有序的数据，内层循环几乎不需要移动元素，每次插入只需O(1)，总体接近O(n)。

第23题 答案：错

选择排序最坏情况下交换次数为O(n)（每轮最多交换1次）。冒泡排序最坏情况下交换次数为O(n^2)（逆序时每次比较都交换）。两者不同。

第24题 答案：对

double转int时小数部分被截断（向零取整），如3.9变为3，-2.7变为-2。

第25题 答案：错

unsigned int为无符号类型，不能表示负数。0u-1会发生无符号下溢，结果为UINT_MAX（32位下为4294967295），而不是-1。

编程题1：最大公约数与最小公倍数

#include <iostream>
using namespace std;

long long gcd(long long a, long long b) {
    while (b != 0) {
        long long t = b;
        b = a % b;
        a = t;
    }
    return a;
}

long long lcm(long long a, long long b) {
    return a / gcd(a, b) * b;
}

int main() {
    int n;
    cin >> n;
    long long g, l;
    cin >> g;
    l = g;
    for (int i = 1; i < n; i++) {
        long long x;
        cin >> x;
        g = gcd(g, x);
        l = lcm(l, x);
    }
    cout << g << " " << l << endl;
    return 0;
}

编程题2：杨辉三角

#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    int n;
    cin >> n;
    int a[20][20] = {0};
    for (int i = 0; i < n; i++) {
        a[i][0] = 1;
        a[i][i] = 1;
        for (int j = 1; j < i; j++)
            a[i][j] = a[i-1][j-1] + a[i-1][j];
    }
    for (int i = 0; i < n; i++) {
        for (int j = 0; j <= i; j++)
            cout << setw(4) << a[i][j];
        cout << endl;
    }
    return 0;
}
