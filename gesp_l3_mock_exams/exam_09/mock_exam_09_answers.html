单选题详细解析

第1题 答案：C

0x3F = 3×16 + 15 = 48 + 15 = 63。

第2题 答案：B

45的二进制为00101101，取反得11010010，加1得11010011。所以-45的补码是11010011。

第3题 答案：D

0xAB = 10×16+11 = 171，二进制为10101011。右移4位得00001010=10（即0xA=10）。与0x0F（00001111）按位与得00001011=11（即0xB=11）。输出"10 11"。

第4题 答案：A

将第3位设为1用"或"操作：x | (1 << 3)。B选项是"与"操作会清除其他位；C选项是"异或"会翻转该位；D选项x|3是设置第0和第1位。

第5题 答案：B

0xC5 = 11000101。异或0xFF（11111111）相当于按位取反：00111010 = 0x3A。

第6题 答案：C

八进制转二进制，每位八进制对应3位二进制：1→001, 7→111, 5→101。所以0175 = 001 111 101 = 01111101。

第7题 答案：D

p = a+2 指向a[2]=30。p++后p指向a[3]=40。*p = 40。

第8题 答案：A

*(p+4) = arr[4] = 5，*(p+1) = arr[1] = 1。5 - 1 = 4。

第9题 答案：C

冒泡排序一趟（从前往后相邻比较交换大的）： (5,3)→交换→{3,5,8,2,7}; (5,8)→不换; (8,2)→交换→{3,5,2,8,7}; (8,7)→交换→{3,5,2,7,8}。 结果：3 5 2 7 8。注意A和C选项相同，正确答案是C。

第10题 答案：B

这是斐波那契数列：f(0)=0, f(1)=1, f(2)=1, f(3)=2, f(4)=3, f(5)=5, f(6)=8。

第11题 答案：A

f(5)调用f(4)，f(4)调用f(3)，...f(1)调用f(0)。从f(5)到f(0)共调用了6次。

第12题 答案：D

*a = a[0] = 1，*(a+1) = a[1] = 2，*(a+2) = a[2] = 3。1+2+3 = 6。

第13题 答案：C

统计1到100中数字7出现的次数。个位是7的：7,17,27,37,47,57,67,77,87,97共10个。十位是7的：70,71,72,73,74,75,76,77,78,79共10个。其中77被数了两次（个位和十位各一次）。总共 10+10 = 20次。

第14题 答案：B

*p就是x=100。100/4=25, 100%7=2。25+2=27。所以x变为27。

第15题 答案：A

a[i] & (a[i]-1) 的作用是清除a[i]最低位的1： 6=0110, 5=0101, 6&5=0100=4；10=1010, 9=1001, 10&9=1000=8；12=1100, 11=1011, 12&11=1000=8；9=1001, 8=1000, 9&8=1000=8。 sum = 4+8+8+8 = 28。

判断题详细解析

第16题 答案：F（错）

(int)3.9 = 3，(int)4.1 = 4，3+4 = 7，不是8。强制类型转换为int是截断小数部分（向零取整），不是四舍五入。

第17题 答案：F（错）

3/2在整数除法中结果为1（向零截断），1*2=2。所以a=2，不是3。整数除法会丢失小数部分，运算顺序从左到右。

第18题 答案：F（错）

int *p; 只声明了指针但未初始化，p指向随机地址（野指针）。对野指针解引用赋值是未定义行为，极其危险。必须先让p指向有效内存（如 p = new int; 或 p = &x;）。

第19题 答案：T（对）

当p指向数组首元素时，p[i]等价于*(p+i)，也等价于a[i]。所以p[3]和a[3]完全等价。

第20题 答案：F（错）

选择排序无论最好还是最坏情况，时间复杂度都是O(n^2)，因为每轮都要扫描剩余元素找最小值。不像冒泡排序可以通过标记提前终止。

第21题 答案：T（对）

冒泡排序只在相邻元素严格大于时交换，相等元素不交换，所以稳定。选择排序在交换时可能改变相等元素的相对顺序，如{5a, 5b, 3}第一轮把5a和3交换，5b就跑到5a前面了，所以不稳定。

第22题 答案：T（对）

unsigned int的0减1发生下溢，按模2^32运算，结果为4294967295（即UINT_MAX），是一个非常大的正数。

第23题 答案：F（错）

(char)256：256超出了char范围（-128~127或0~255）。对于signed char，256 mod 256 = 0，即'\0'（空字符），不是'1'。即使对unsigned char，256 mod 256 = 0。

第24题 答案：T（对）

对于32位int，1<<31将1移到符号位，结果是10000000 00000000 00000000 00000000，即-2147483648（INT_MIN）。注意：C++17起这是未定义行为，但在大多数实现中结果为INT_MIN。

第25题 答案：F（错）

~0是对0的所有位取反，0的二进制全是0，取反后全是1，即11111111...11111111。对于int类型，这是-1（补码表示）。不是0。

编程题1：表达式求值

#include <iostream>
#include <string>
#include <vector>
using namespace std;

int main() {
    string expr;
    cin >> expr;

    // 解析数字和运算符
    vector<int> nums;
    vector<char> ops;
    int num = 0;
    for (int i = 0; i <= expr.size(); i++) {
        if (i == expr.size() || expr[i] == '+' || expr[i] == '-' ||
            expr[i] == '*' || expr[i] == '/') {
            nums.push_back(num);
            if (i < expr.size()) ops.push_back(expr[i]);
            num = 0;
        } else {
            num = num * 10 + (expr[i] - '0');
        }
    }

    // 先处理乘除
    vector<int> nums2;
    vector<char> ops2;
    nums2.push_back(nums[0]);
    for (int i = 0; i < ops.size(); i++) {
        if (ops[i] == '*') {
            nums2.back() *= nums[i+1];
        } else if (ops[i] == '/') {
            nums2.back() /= nums[i+1];
        } else {
            ops2.push_back(ops[i]);
            nums2.push_back(nums[i+1]);
        }
    }

    // 再处理加减
    int result = nums2[0];
    for (int i = 0; i < ops2.size(); i++) {
        if (ops2[i] == '+') result += nums2[i+1];
        else result -= nums2[i+1];
    }

    cout << result << endl;
    return 0;
}

编程题2：迷宫最短路径

#include <iostream>
#include <queue>
using namespace std;

int maze[105][105];
int vis[105][105];
int dx[] = {0, 0, 1, -1};
int dy[] = {1, -1, 0, 0};

int main() {
    int n, m;
    cin >> n >> m;
    for (int i = 0; i < n; i++)
        for (int j = 0; j < m; j++)
            cin >> maze[i][j];

    if (n == 1 && m == 1) { cout << 0; return 0; }

    queue<pair<int,int>> q;
    q.push({0, 0});
    vis[0][0] = 1;
    int steps = 0;

    while (!q.empty()) {
        steps++;
        int sz = q.size();
        for (int k = 0; k < sz; k++) {
            auto [x, y] = q.front(); q.pop();
            for (int d = 0; d < 4; d++) {
                int nx = x + dx[d], ny = y + dy[d];
                if (nx >= 0 && nx < n && ny >= 0 && ny < m
                    && !vis[nx][ny] && maze[nx][ny] == 0) {
                    if (nx == n-1 && ny == m-1) {
                        cout << steps;
                        return 0;
                    }
                    vis[nx][ny] = 1;
                    q.push({nx, ny});
                }
            }
        }
    }
    cout << -1;
    return 0;
}
