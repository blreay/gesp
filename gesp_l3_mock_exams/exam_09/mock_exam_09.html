三、编程题（每题 25 分，共 50 分）

编程题 1：表达式求值

题目描述：

输入一个含 +、-、*、/ 和非负整数的表达式字符串（无括号、无空格），按运算符优先级计算结果。整除向零取整。

输入格式：

一行一个合法的表达式字符串（长度不超过1000，中间结果和最终结果保证在int范围内，不会出现除以0的情况）。

输出格式：

一个整数，表示表达式的计算结果。

样例输入1

3+2*4-6/3

样例输出1

9

解释：先算乘除：2*4=8, 6/3=2，再算加减：3+8-2=9。

样例输入2

100-50*2+25

样例输出2

25

解释：50*2=100，100-100+25=25。

编程题 2：迷宫最短路径

题目描述：

给定一个N×M的迷宫，0表示通路，1表示墙壁。从左上角(0,0)出发到达右下角(N-1,M-1)，每次可以上下左右移动一格。求最短路径的步数，如果不可达则输出-1。

输入格式：

第一行两个正整数 N 和 M（1 ≤ N, M ≤ 100）

接下来 N 行，每行 M 个整数（0或1），表示迷宫。

保证起点(0,0)和终点(N-1,M-1)都是0。

输出格式：

一个整数，表示最短路径长度（步数）。不可达输出-1。

样例输入1

3 3
0 0 0
0 1 0
0 0 0

样例输出1

4

样例输入2

3 3
0 1 0
1 1 0
0 0 0

样例输出2

-1
