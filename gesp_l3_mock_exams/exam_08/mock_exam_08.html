三、编程题（每题 25 分，共 50 分）

编程题 1：水仙花数扩展（N位自恋数）

题目描述：

给定范围[L, R]和位数N，找出该范围内所有的N位自恋数。N位自恋数是指一个N位数，其各位数字的N次方之和等于该数本身。如果不存在这样的数，输出"None"。

输入格式：

一行三个整数 L, R, N（1 ≤ L ≤ R ≤ 10^7, 1 ≤ N ≤ 7），保证L和R都是N位数。

输出格式：

每行输出一个满足条件的自恋数（升序）。如果没有，输出"None"。

样例输入1

100 999 3

样例输出1

153
370
371
407

样例输入2

200 300 3

样例输出2

None

编程题 2：稀疏矩阵压缩

题目描述：

输入一个M行N列的整数矩阵，输出其中所有非零元素的三元组表示（行号, 列号, 值）。行号和列号从1开始。三元组按行优先、同行按列递增的顺序输出。

输入格式：

第一行两个正整数 M, N（1 ≤ M, N ≤ 100）

接下来 M 行，每行 N 个整数，表示矩阵元素（元素绝对值不超过1000）。

输出格式：

第一行输出非零元素的个数 k。

接下来 k 行，每行三个整数，表示一个非零元素的（行号, 列号, 值），用空格分隔。

如果没有非零元素，只输出0。

样例输入

3 4
0 0 3 0
0 0 0 0
0 2 0 5

样例输出

3
1 3 3
3 2 2
3 4 5
