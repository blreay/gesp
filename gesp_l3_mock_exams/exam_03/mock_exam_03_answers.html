单选题详细解析

第1题 答案：A

2B(十六进制)转十进制：2×16+11=43。43转八进制：43÷8=5...3，即53(八进制)。验证：5×8+3=43。

第2题 答案：C

1010(二进制)=1×8+0×4+1×2+0=10(十进制)。12(八进制)=1×8+2=10(十进制)。两者相等。

第3题 答案：B

n&(n-1)的效果是清除n二进制表示中最低位的1。例如n=12(1100)，n-1=11(1011)，n&(n-1)=1000=8，最低位的1(第2位)被清除。

第4题 答案：A

清零某一位用"与非"操作：1<<3产生00001000，取反得11110111，与x相与可以只将第3位清零而不影响其他位。

第5题 答案：B

-1的补码是全1(11...1)。大多数编译器对有符号数右移执行算术右移（高位补符号位1），右移后仍然是全1，即-1。

第6题 答案：A

10000001(补码)=-127，11111111(补码)=-1。-127+(-1)=-128，-128的8位补码是10000000。没有溢出（-128在8位补码范围内）。

第7题 答案：C

C++中二维数组可以省略第一维的大小（编译器根据初始化列表推断），但第二维必须指定。只有C选项int a[][2]满足此要求。

第8题 答案：C

二维数组按行优先存储。a[1][2]在内存中的偏移量=1×4+2=6个int位置。指针相减得到的是元素个数差：6。

第9题 答案：C

'a'+3的结果是整数100（=97+3）。当赋值给char变量或用%c输出时显示为字符'd'(ASCII 100)。作为int值就是100。所以A和B都正确。

第10题 答案：B

substr(pos, len)从位置pos开始截取len个字符。s.substr(1,3)从下标1开始取3个字符：s[1]='e', s[2]='l', s[3]='l'，结果是"ell"。

第11题 答案：B

C++中局部变量会遮蔽(shadow)同名的全局变量。在函数内部，直接使用该名字访问的是局部变量。若需访问全局变量，需使用::运算符。

第12题 答案：B

static局部变量只在第一次执行到声明时初始化一次，此后函数返回时不销毁，下次调用时保持上次的值。它存储在静态存储区而非栈上。

第13题 答案：B

内层循环执行次数：i=1时1次，i=2时2次，i=3时3次，i=4时4次。总共1+2+3+4=10次。

第14题 答案：B

f(5)=5+f(4)=5+4+f(3)=5+4+3+f(2)=5+4+3+2+f(1)=5+4+3+2+1+f(0)=5+4+3+2+1+0=15。

第15题 答案：B

p指向a的地址，*p=20通过指针修改了a所在内存的值。因此a的值变为20。输出20。

判断题详细解析

第16题 答案：对

F(十六进制)=15(十进制)，15>14，所以F比14大。

第17题 答案：错

位数多不一定值大。例如10(二进制，2位)=2，而1(二进制，1位)=1，虽然前者位数多且值大；但100(3位)=4 vs 11111(5位)=31就是位数少但值小的例子。关键反例：1000...0有很多位但可能比位数少的1111...1小（不对）。真正的反例是允许前导零时，如0001(4位)=1比11(2位)=3小。

第18题 答案：对

-n在补码中等于按位取反加1。n&(-n)只保留最低位的1。例如n=6(110)，-n的补码=...11111010，6&(-6)=010=2，即最低位的1对应的值。

第19题 答案：对

右移对负奇数执行的是向负无穷取整的除法。例如-3>>1=-2（算术右移，11...101右移得11...110=-2），而-3/2=-1（C++向零取整）。两者结果不同。

第20题 答案：错

函数声明（原型）通常放在头文件中，函数定义放在源文件中。编译时通过链接器将声明和定义关联起来，不要求在同一文件中。

第21题 答案：错

C++不允许在函数体内定义另一个函数（不支持嵌套函数定义）。虽然C++11的lambda表达式在语法上类似，但传统函数定义不能嵌套。

第22题 答案：对

部分初始化时，未显式初始化的元素自动初始化为0。int a[10]={1}表示a[0]=1，a[1]到a[9]都是0。

第23题 答案：对

C/C++中二维数组按行优先（row-major）连续存储。a[0][0], a[0][1], ..., a[0][n-1], a[1][0], ... 在内存中依次排列。

第24题 答案：错

strlen计算字符串长度，不包含结束符'\0'。"abc"有3个字符，strlen返回3，不是4。注意与sizeof的区别（sizeof("abc")=4，包含'\0'）。

第25题 答案：对

指针变量需要存储一个内存地址，因此它本身也占内存空间。在32位系统中占4字节，64位系统中占8字节。

编程题1：密码生成器（凯撒加密）

#include <iostream>
#include <string>
using namespace std;

int main() {
    string s;
    int k;
    getline(cin, s);
    cin >> k;
    k = k % 26; // 处理k>=26的情况
    for (int i = 0; i < (int)s.size(); i++) {
        char c = s[i];
        if (c >= 'a' && c <= 'z') {
            s[i] = 'a' + (c - 'a' + k) % 26;
        } else if (c >= 'A' && c <= 'Z') {
            s[i] = 'A' + (c - 'A' + k) % 26;
        }
        // 数字和特殊字符不变
    }
    cout << s << endl;
    return 0;
}

思路：遍历每个字符，如果是字母则循环移位k位（用取模运算实现循环），非字母字符保持不变。注意大小写分别处理。

编程题2：数组旋转（三次反转法）

#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    int n, k;
    cin >> n >> k;
    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];

    k = k % n; // 处理k>=n的情况
    if (k == 0) {
        for (int i = 0; i < n; i++) {
            if (i > 0) cout << " ";
            cout << a[i];
        }
        cout << endl;
        return 0;
    }

    // 三次反转法
    // 1. 反转整个数组
    reverse(a.begin(), a.end());
    // 2. 反转前k个元素
    reverse(a.begin(), a.begin() + k);
    // 3. 反转后n-k个元素
    reverse(a.begin() + k, a.end());

    for (int i = 0; i < n; i++) {
        if (i > 0) cout << " ";
        cout << a[i];
    }
    cout << endl;
    return 0;
}

思路：右旋转K位等价于：将数组最后K个元素移到前面。三次反转法：(1)整体反转，(2)反转前K个，(3)反转后N-K个。注意先将K对N取模。时间复杂度O(N)，空间复杂度O(1)（不计输入数组）。
