单选题详细解析

第1题 答案：A

八进制37转十进制：3×8+7=31。31转十六进制：31÷16=1...15(F)，所以31=1F(十六进制)。

第2题 答案：C

十六进制加法：A(=10)+9=19(十进制)。19转十六进制：19÷16=1...3，即13(十六进制)。注意题目问的是十六进制结果。

第3题 答案：C

~0将0的所有位取反，32位int中得到全1（即11111111 11111111 11111111 11111111），这是-1的补码表示。

第4题 答案：B

由于运算符优先级，x&1==1 等价于 x&(1==1) 即 x&1，不是比较结果。需要加括号 (x&1)==1 才能正确判断奇偶。

第5题 答案：A

7的二进制=111，3的二进制=011。7|3=111=7，7&3=011=3。7^3：111^011=100=4。

第6题 答案：A

最高位是1，为负数。取反+1求绝对值：11110101取反=00001010=10，加1=00001011=11。所以原数是-11。

第7题 答案：C

有符号int溢出在C++标准中属于未定义行为，但在大多数实现中表现为结果回绕（wrap around）。不会产生编译错误或运行时异常。

第8题 答案：B

char s[] = "GESP" 包含4个字符加1个结束符'\0'，共5个字节。sizeof计算的是数组占用的总字节数。

第9题 答案：C

C++不进行数组边界检查。越界访问不会导致编译错误（编译器不检查），也不一定产生运行时错误，而是导致未定义行为。

第10题 答案：B

A选项中两个字符串字面量不能直接用+拼接（它们是const char*类型）。B正确，string对象可以和字符串字面量用+拼接。C中cd没有引号，语法错误。

第11题 答案：B

f(0)=1, f(1)=1, f(2)=f(1)+f(0)=1+1=2, f(3)=f(2)+f(1)=2+1=3, f(4)=f(3)+f(2)=3+2=5。这是类斐波那契递归。

第12题 答案：C

局部变量在函数返回后就被销毁了，返回其引用会导致悬空引用(dangling reference)，使用它属于未定义行为。编译器可能给出警告但不是语法错误。

第13题 答案：A

冒泡排序第一趟从左到右比较相邻元素：5>3交换得{3,5,1,4,2}; 5>1交换得{3,1,5,4,2}; 5>4交换得{3,1,4,5,2}; 5>2交换得{3,1,4,2,5}。最大的5已冒泡到末尾。

第14题 答案：B

二分查找要求数据有序（升序或降序），这是其核心前提。元素可以重复，长度可以是奇数或偶数，元素可以是任意可比较的值。

第15题 答案：B

n&(n-1)每次清除n最低位的1。13=1101(二进制)，有3个1。执行过程：1101&1100=1100(cnt=1); 1100&1011=1000(cnt=2); 1000&0111=0000(cnt=3); n=0循环结束。输出3。

判断题详细解析

第16题 答案：对

8位补码：最高位为符号位，可表示-128(10000000)到127(01111111)，共256个数。

第17题 答案：错

16位unsigned short最大值是2^16-1=65535，不是65536。65536=2^16，超出了16位能表示的范围。

第18题 答案：对

异或的性质：a^b^b = a^(b^b) = a^0 = a。任何数异或自身得0，任何数异或0得自身。

第19题 答案：错

当a很大时(如INT_MAX)，a*2溢出属于未定义行为，而a<<1的行为也是未定义的（对有符号数左移导致溢出时）。两者在溢出情况下行为不保证相同。

第20题 答案：对

数组名在大多数表达式中退化为指向首元素的指针。例外情况：sizeof(数组名)和&数组名时不退化。

第21题 答案：错

sizeof(数组名)得到的是整个数组的字节数，不是指针大小。这是数组名不退化的例外情况之一。例如int a[5]; sizeof(a)=20（32位系统）。

第22题 答案：对

选择排序在交换时可能改变相同元素的相对顺序。例如{5a, 5b, 3}，第一轮选出最小值3与5a交换，5a跑到了5b后面，稳定性被破坏。

第23题 答案：对

优化版冒泡排序设置标志位，如果某一趟没有发生任何交换，说明数组已有序，提前终止。对已排序数组只需一趟扫描，时间复杂度O(n)。

第24题 答案：错

C++函数参数默认以值传递方式传递。需要显式使用&声明引用参数才能实现引用传递。

第25题 答案：对

void函数没有返回值，合法且常用。例如void print() { cout << "hello"; } 不需要return语句（或使用空return;）。

编程题1：回文判断

#include <iostream>
#include <string>
#include <cctype>
using namespace std;

bool isPalindrome(const string& s) {
    string filtered;
    for (char c : s) {
        if (isalnum(c)) {
            filtered += tolower(c);
        }
    }
    int left = 0, right = (int)filtered.size() - 1;
    while (left < right) {
        if (filtered[left] != filtered[right]) return false;
        left++;
        right--;
    }
    return true;
}

int main() {
    int n;
    cin >> n;
    cin.ignore();
    for (int i = 0; i < n; i++) {
        string s;
        getline(cin, s);
        cout << (isPalindrome(s) ? "Y" : "N") << endl;
    }
    return 0;
}

思路：先过滤出字母和数字并转小写，然后用双指针从两端向中间比较。注意使用getline读取可能包含空格的字符串。

编程题2：成绩统计

#include <iostream>
#include <string>
#include <vector>
#include <algorithm>
using namespace std;

struct Student {
    string name;
    int s1, s2, s3, total;
    int order; // 输入顺序
};

int main() {
    int n;
    cin >> n;
    vector<Student> stu(n);
    for (int i = 0; i < n; i++) {
        cin >> stu[i].name >> stu[i].s1 >> stu[i].s2 >> stu[i].s3;
        stu[i].total = stu[i].s1 + stu[i].s2 + stu[i].s3;
        stu[i].order = i;
    }
    stable_sort(stu.begin(), stu.end(), [](const Student& a, const Student& b) {
        return a.total > b.total;
    });
    for (int i = 0; i < n; i++) {
        cout << (i + 1) << " " << stu[i].name << " " << stu[i].total << endl;
    }
    return 0;
}

思路：读入数据后计算总分，使用stable_sort按总分降序排序（保持相同总分的输入顺序），输出排名、姓名和总分。
